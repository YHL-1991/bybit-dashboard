전혀 하지 않습니다. 견적 · 작업 · 인도 모든 단계에서 매매 전략 · 종목 · 진입 시점은 의뢰자께서 직접 정의 · 제공해주셔야 합니다. "어떤 전략이 좋을까요" "이 코인 어때요" 등의 질문에 대해서도 답변드리지 않으며, 이는 본 서비스가 소프트웨어 개발 용역임을 법적으로 명확히 유지하기 위함입니다. 양해 부탁드립니다.

실거래 API 키를 드려야 하나요?

드리지 마십시오. 본 작업 중 의뢰자의 실거래 API 키는 어떠한 경우에도 받지 않습니다. 테스트넷 또는 페이퍼 트레이딩 키만 사용하며, 실거래 키는 의뢰자께서 환경변수로 직접 관리하시기 바랍니다. 또한 API 키 발급 시 출금 권한(Withdraw)은 반드시 비활성화하시고, IP 화이트리스트를 설정하실 것을 권장드립니다.

거주국에서 해당 거래소 이용이 가능한가요?

거주국별 거래소 이용 가능 여부 · 관련 법령(외환거래법 · 특정금융정보법 등) 준수는 의뢰자 본인의 책임입니다. 본 서비스는 코드 개발에 한정되며 법령 검토를 제공하지 않습니다. 견적 단계에서 본인 확인 메시지("저는 OO국 거주이며 해당 거래소 사용 가능을 확인했습니다")를 요청드릴 수 있습니다.

제 매매 전략이 수익이 날까요?

본 서비스는 코드 개발 외주이며, 의뢰자께서 제공하신 전략의 수익성 · 유효성은 의뢰자 본인의 책임입니다. 실거래 적용 전 충분한 백테스트와 페이퍼 트레이딩으로 검증하시기를 권장드립니다.

Velox 데모와 동일한 수익이 나나요?

아닙니다. Velox 데모는 분석 · 시각화 도구로 표시되는 시그널 점수 · 백테스트 수치는 과거 데이터에 기반한 추정값입니다. 동일한 시스템을 구현해드린다고 해서 동일한 수익이 발생하지 않습니다. 시장 환경 · 자본 규모 · 슬리피지 · 의뢰자가 제공하신 전략에 따라 결과는 본인의 백테스트와도 다를 수 있습니다.

실거래 중 손실이 발생하면 책임지시나요?

본 서비스는 인도된 코드의 정상 동작에 대한 책임만 부담합니다. 매매 손익 · 거래소 정책 변경 · 시장 변동성 · 레버리지 강제 청산에 의한 영향은 전적으로 의뢰자 본인의 책임이며, 손해배상 한도는 의뢰 금액을 초과하지 않습니다.

어떤 거래소를 지원하시나요?
