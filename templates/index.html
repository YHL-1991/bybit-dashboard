스마트머니 다이버전스 스캐너
"스캔"을 눌러 전 종목을 훑습니다 (~10초).

L/S는 개미 3사 평균(Binance·OKX·Bybit) vs 고래 2사 평균(Binance·OKX), OI는 Binance 미체결약정. 고래 주도 급등 = 24h 급등(+2%↑) + 고래 ≥ 1.2 + 고래−개미 갭 ≥ 0.4 (고래가 개미보다 압도적 롱, 예: OPG). 반등 후보 = 24h 하락 + 고래 롱 + 개미 숏. 하락 후보 = 24h 급등 + 개미 롱 + 고래 숏. 갭 클수록 괴리 큼(상단부터 강함). 고래주도는 모멘텀(추종), 반등/하락은 컨트래리언 가설일 뿐 매매신호 아님. 고래도 틀립니다.

다거래소 포지션 심리 추이 (48시간, 1h봉)
미결제약정 (OI) 추이 (Binance)
롱/숏 비율: 개미(3사 평균) vs 고래(2사 평균)

개미 = Binance/OKX/Bybit 전체계정 평균, 고래 = Binance/OKX 상위트레이더 평균 (Bybit는 고래 데이터 미공개).
OI 추이: OI 상승 + 가격 상승 = 신규 롱(강세) / OI 상승 + 가격 하락 = 신규 숏(약세) / OI 하락 = 청산.
L/S 격차: 개미와 고래가 크게 벌어지면 컨트래리언 시그널. 예) 개미 1.8 / 고래 0.7 = 개미 롱과열, 고래 숏, 하락 가능.
